Private Repository Access

Add a GitHub Personal Access Token

  1. 1

    Open GitHub Token Settings to create a new Fine-grained token.

  2. 2

    Set Repository access to All repositories. Then, under Repository permissions, set Contents to Read-only.

  3. 3

    Click Generate token at the bottom, then copy and paste it here.

Your token is stored only in your browser's local storage and is forwarded directly to GitHub's API. It is never logged or persisted on our servers.
